# fitshit

A web-based calisthenics workout planner app.

## Features

- Generate an AI-style workout plan from goal, level, duration, and weekly schedule
- Configure equipment availability
- Configure **adjustable dumbbell min/max** and **kettlebell min/max** ranges
- Preview workout rounds before generating
- Track workout completion per day
- Built-in round timer

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
